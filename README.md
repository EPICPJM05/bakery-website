# SmartPresence - AI-Driven Face Recognition & CCTV Attendance Platform

A modern, responsive website showcasing SmartPresence's AI-powered facial recognition and attendance management platform. Built with HTML5, CSS3, JavaScript, and Bootstrap 5.

## 🌟 Features

### Design & User Experience
- **Modern, Professional Design**: Clean layout with professional blue color palette
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Interactive Elements**: Smooth animations, hover effects, and dynamic content
- **Accessibility**: WCAG compliant with proper focus states and keyboard navigation

### Key Sections
1. **Hero Section**: Dynamic camera feed simulation with face detection animation
2. **Features**: Technical capabilities showcase (edge processing, anti-spoofing, etc.)
3. **Proof Points**: Accuracy benchmarks and client metrics with animated counters
4. **Case Studies**: Real-world implementation examples with anonymized data
5. **Partner Integrations**: Compatible CCTV vendors and VMS systems
6. **Trust Seals**: ISO certifications and privacy compliance badges
7. **Blog/News**: Latest updates and feature announcements
8. **Demo CTA**: Prominent call-to-action for demo requests

### Technical Features
- **Bootstrap 5**: Modern CSS framework for responsive design
- **Custom CSS**: Professional styling with CSS custom properties
- **Vanilla JavaScript**: Interactive features without heavy dependencies
- **Font Awesome**: Professional icons throughout the interface
- **Google Fonts**: Inter font family for modern typography

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies required

### Installation
1. Clone or download the project files
2. Open `index.html` in your web browser
3. The website will load with all features ready to use

### File Structure
```
SmartPresence/
├── index.html          # Main HTML file
├── styles.css          # Custom CSS styles
├── script.js           # JavaScript functionality
└── README.md           # Project documentation
```

## 🔧 Customization

### Modifying Colors
Update the CSS custom properties in `styles.css`:
```css
:root {
    --primary-color: #2563eb;
    --primary-dark: #1d4ed8;
    /* ... other colors */
}
```

### Adding New Sections
1. Add HTML structure in `index.html`
2. Style with CSS classes in `styles.css`
3. Add any JavaScript functionality in `script.js`

### Updating Content
- **Hero Section**: Modify the headline and description in the hero section
- **Features**: Update feature cards with new capabilities
- **Proof Points**: Change metrics and benchmarks as needed
- **Case Studies**: Replace with actual client implementations
- **Blog Posts**: Add new articles and updates
